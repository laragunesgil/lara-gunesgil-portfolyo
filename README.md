# Lara Güneşgil — Sosyoloji Portfolyosu

Portfolyo sitesi. HTML, CSS ve JavaScript dosyaları bu deponun kök dizinindedir.

İletişim sayfasındaki form yalnızca tarayıcı içi doğrulama örneğidir; mesaj göndermez ve veri kaydetmez. Projeler sayfasında iki doğrulanmış ders çalışması ve ayrı etiketlenmiş üç yeni portfolyo demosu bulunur.

GitHub Pages yayını etkinleştirmek için **Settings → Pages → Deploy from a branch** bölümünde `main` dalı ve `/ (root)` klasörünü seçin.

Canlı bağlantı: henüz yayımlanmadı.
